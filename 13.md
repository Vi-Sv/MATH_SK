## 🧱 Универсальный архитектурный скелет решения (Метод зажатия неравенствами для старших степеней)
------------------------------
## 1. Входные параметры (Сбор метаданных)

* Уравнение структуры: Алгебраическое выражение, содержащее старшие степени одной переменной (например, x³, x⁴) и связанные с ней выражения с другими переменными (например, y² или y).
* Ограничение ОДЗ целого контура:
* [Натуральные числа] ($\mathbb{N}$) → x ≥ 1, y ≥ 1.
   * [Целые числа] ($\mathbb{Z}$) → x, y ∈ (-∞; +∞).

------------------------------
## 2. Конвейер вычислений (Алгоритм)

* Шаг 1. Выделение точного многочлена (Генерация_Границ)
Выражаем переменную младшей степени (например, y²) через многочлен от переменной старшей степени x. Наша цель — найти два последовательных полных квадрата (или куба), между которыми намертво зажато выражение для y².
1. Изучаем ведущие слагаемые многочлена (например, x² + 2x...).
   2. Строим ближайший полный квадрат сверху: (x + k)².
   3. Строим ближайший полный квадрат снизу: (x + k - 1)².
* Шаг 2. Развертывание вилки неравенств (Жесткое_Зажатие)
Записываем строгое двойное неравенство для выражения, равного y²:
$$(x + k - 1)^2 < y^2 < (x + k)^2$$ 
В целых числах между двумя последовательными квадратами целых чисел (например, между 16 и 25 квадратных целых чисел нет, идет разрыв) не может находиться никакой другой полный квадрат.
* Шаг 3. Локализация зоны поиска (Точечный_Перебор)
Двойное неравенство из Шага 2 выполняется для всех x, кроме узкого диапазона значений, где строгие знаки ломаются из-за остаточных членов многочлена.
1. Решаем неравенства относительно x. Получаем конечный список критических точек (обычно x может принимать всего несколько значений, например, от -3 до 3).
   2. Если для каких-то x выражение точно совпадает с границей, проверяем граничные равенства: y² = (x+k)² или y² = (x+k-1)².
* Шаг 4. Финальный фильтр и вывод корней
Поочередно подставляем выделенные критические значения x в исходное уравнение. Находим соответствующие целые значения y. Пары, не дающие целых корней, отбрасываем.

------------------------------
## ⚠️ Архитектурный капкан (ОТК)
Ловушка четности знака: При извлечении корня из равенства y² = K² всегда возникает два разветвления: y = K и y = -K. Если контур задачи — [Целые числа], игнорирование отрицательного корня приведет к потере 50% правильного ответа.
