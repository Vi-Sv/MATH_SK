## 🧱 Универсальный архитектурный скелет решения (Гипергеометрический выбор / Извлечение без возвращения)
------------------------------
## 1. Входные параметры (Сбор метаданных)

* Общий объем хранилища (N): Полное количество элементов в исходной базе данных (генеральной совокупности).
* Архитектура пула (Целевые vs Остальные): Спецификация элементов по категориям:
* Целевые_Элементы (K) — количество интересующих нас объектов (например, профильные резюме, работающие сервера, бракованные детали).
   * Остальные_Элементы (N - K) — фоновые объекты.
* Параметры выборки (n): Количество элементов, которые извлекаются за один шаг (одним пакетом) без возвращения обратно в общее хранилище.
* Критерий триггера (k): Строгое количество целевых элементов, которое должно оказаться в извлеченном пакете размера n.

------------------------------
## 2. Конвейер вычислений (Алгоритм)

* Шаг 1. Расчет ОДЗ выборки (Знаменатель)
Вычисляем общее число способов вытащить пакет из n элементов из хранилища объемом N без учета их типов. Применяется классическая формула сочетаний $C_N^n$:
$$Знаменатель = C_N^n = \frac{N!}{n! \cdot (N - n)!}$$ 
* Шаг 2. Расчет успешных конфигураций (Числитель)
Пакет должен состоять из двух изолированных частей: ровно k целевых элементов и ровно (n - k) остальных.
1. Находим число способов выбрать целевые элементы: $C_K^k$.
   2. Находим число способов выбрать остальные элементы: $C_{N - K}^{n - k}$.
   3. Перемножаем эти независимые комбинации, чтобы получить полную массу успешных исходов:
   $$Числитель = C_K^k \cdot C_{N - K}^{n - k}$$ 
* Шаг 3. Вывод финального отчета (Вероятность_События)
Делим массу успешных конфигураций на общее число возможных пакетов в рамках ОДЗ:
$$P(X = k) = \frac{Числитель}{Знаменатель} = \frac{C_K^k \cdot C_{N - K}^{n - k}}{C_N^n}$$ 

------------------------------
## ⚠️ Архитектурный капкан (ОТК)
Граничные ограничения параметров: Если требуемое число успехов k превышает общее количество целевых элементов в баке (k > K) или размер всей выборки (k > n), то такое событие физически невозможно. Числитель автоматически обращается в 0.
